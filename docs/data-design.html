1 — Overview

Pi-Harness has no relational store. The write side is the pi-subagents extension forking child sessions; the read side tails files. This gives durability for free (even if parent terminal detaches) and debuggability via ls + cat.

<tmpdir>/pi-subagents-uid-0/
  async-subagent-runs/<runId>/          ← per-run durable dir (canonical)
  async-subagent-results/<runId>.json   ← aggregated results
  supervisor-channels/<runId>.steer.json ← steer inbox

/root/.pi/agent/sessions/--workspace--/
  *.jsonl                               ← chat transcripts (append-only)

/workspace/.pi/agent/...                ← host-mounted agent cards
Invariant (T4)
If a file is not on this bus, it is not observable. Dashboard never fabricates fleetState except via reconciler mapping + stale guard.

Reconciliation rules (must)
dashboardStatus = state pending|running→running, paused→waiting, complete→done, failed|stopped→error (server.js:96) + stale (now-lastUpdate>30s) ⇒ failed with duration frozen (:49) + sort startedAt desc (:125).

Tail fallback when output-*.log is absent (server.js:85): 5 last events mapped to {ts,kind:'tool', text: `${type}: ${json.slice(0,80)}`}.

2.3 output-*.log — live tail (unstructured)

  • Primary read is output-*.log sorted lexicographically, last file → split '\n' → last 8 lines (server.js:74) → kind by /ERR|error|WARN/ → err, /\[.*\]/ → tool, else out (log lines are 120ch truncated).
  • Modal reads bounded form: requestedLines min(max(parse(lines||50),1),200), 64KB slice, totalBytes reported.

2.4 process-terminal.json — proof file

// when observed (parent saw runner close + lease free):
{"observed": true, "status": "observed", "proof": "observed"}
// candidate (private runner evidence) or missing:
{"observed": false}  or  file absent → processTerminal = unknown (server.js:118)

UI badge: ● observed (green) else ○ unknown amber (App.tsx:199) — never infer from endedAt.

Parser parseSessionFile(:129): counts lines, extracts title (c.text slice 0,30) + preview 0,40 from first type:text, tags by substring (coder>tester>reviewer… else main), time from filename slice 11,16 else mtime (App.tsx:198).

Correlation server.js:175 fleetBySession: Map<sessionFile → FleetEntry> → GET /api/sessions enriches {fleetRunId, fleetState} (single-source proof). Frontend Sidebar uses that map to highlight live sessions (App.tsx:195).

GC policy

  • Visibility GC (TTL): done visible 30 s, error/failed 60 s after lastUpdate (server.js:210); ?all=true bypasses.
  • Physical GC: setInterval 60 s :642 deletes dirs where state∈{failed,complete,stopped,error} && now-lastUpdate>10min — prevents disk leak.

5 — Derived views & indexes

5.1 Derived fleet entry (projection)

derived FleetEntry extends status.json with:
  id = runId.slice(0,8)
  fullId = runId
  dashboardStatus // via map + stale
  tokens, windowTokens, spentTokens // normalized
  elapsed = floor(durationMs/1000) or floor(now-startedAt)
  lines: Tail[8] || Events[5] || info
  transcript: {truncated, totalBytes, maxBytes:64KB}
  processTerminal // observed|unknown

Trap
Do not JSON.parse unbounded logs into memory — read via readFileSync then split('\n') slice. Dispatch must spawn with on('error') or ENOENT crashes Node (server.js:385).

7 — Lifecycle state machine

pending ──► running ──► paused (→ waiting on dashboard) ──► running
   │            │             │
   │            ├─────────────┼──► complete (→ done)  ── TTL 30s visible ── GC 10m
   │            │             └──► failed   (→ error) ── TTL 60s ─────────── GC
   │            └────────────────► stopped  (→ error) ── via stop.requested
   │
   └── stale guard: (running|pending && now-lastUpdate>30s) ⇒ failed (frozen duration) [server.js:49]

Mapping to dashboard is total: every fleet state hits exactly one dashboardStatus. Unknowns remain readable (no inference from endedAt).
