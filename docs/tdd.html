3 — Backend (dashboard/server.js)

3.1 Reconciler readFleetStatus() :25

inputs:  env SUBAGENT_RUNS, ASYNC_RESULTS; FS dirs under SUBAGENT_RUNS
steps:
  1. readdir SUBAGENT_RUNS → dirs (withFileTypes)
  2. per dir: read status.json → parse JSON
  3. state = j.state || j.status || 'unknown'
     agent = j.agent || j.steps[0].agent || workflowKey || 'coder'
     task  = j.task || j.steps[0].task || runId
     times: startedAt, lastUpdate, durationMs?
  4. STALE: if (running||pending && now-lastUpdate>30s) { state=failed; durationMs=lastUpdate-startedAt }
  5. if durationMs==null → (running? now-startedAt : lastUpdate-startedAt) ; clamp <0→0
  6. tokens: if object → total||window||input else number; coerce Number()
  7. tail output-*.log last 8 lines (filter Boolean) → kind by regex; else events.jsonl 5; else info fallback
  8. map dashboardStatus: running|pending→running, paused→waiting, complete→done, failed|stopped→error
  9. windowTokens/spentTokens/totalCost/lifecycle… + processTerminal(observed|unknown via process-terminal.json)
sort: startedAt desc
output: FleetEntry[]
Edge behavior (must stay)
A. Negative duration clamp 0 · B. String totalTokens → Number() · C. Malformed status.json skip not throw (catch) · D. output-*.log tail preserves ts per line (en-GB).

8 — Workflow (coder-tester-loop.js)

args.task → hasFail(s) = s.includes("Test verdict: FAIL")
coder-1: runs.run("coder-1", {agent:"coder", task: implement+commit rules})
tester-1: runs.run("tester-1", {agent:"tester", task: read coder1.output + git diff HEAD~1})
if hasFail(tester1):
  coder-2 → tester-2 → if hasFail → coder-3 → tester-3 → return {rounds:2|3, final}
else return {rounds:1, final:tester1}
catch → {rounds:0, error}

Contracts: coder uses git add + git commit detailed; tester reads git diff HEAD~1 + npm test/typecheck and terminates with Test verdict: PASS/FAIL (or PASS with notes stops) (tester.md:31–48).
