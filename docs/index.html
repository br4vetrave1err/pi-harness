1 — What this is

Pi-Harness runs a fleet of detached pi subagents (pi-subagents extension) whose durable artifacts live under /tmp/pi-subagents-uid-0/async-subagent-runs/<runId>/. Every other surface — dashboard/server.js:25 readFleetStatus(), React Web dashboard/src/App.tsx (1/4 sessions · 3/4 medium windows · SSE/stream), and Bash TTY dashboard.sh — is a stateless projection of that bus. No DB, no queue.

Single source of truth
HTTP GET /api/fleet and CLI dashboard.sh parse identical fields (state map, stale TTL, window/spent, bounded 64KB/200) or docs declare it a bug (G1–G6).
Tracer bullet
Dockerfile:16 pi install → C1 pi list → C2 coder.md bake 91 → C4 spawn subagent → C5 GET /api/fleet → C6 card in <3s — every phase must re-prove this slice.

  • Invariant dashboard/server.js:49 stale running lastUpdate+30s<now → failed (duration frozen) prevents 616 s drift.
  • Bounded GET /api/fleet/:id?lines=200 caps 64 KB/200 msgs; GET /api/session/:id caps 5 MB → 500 KB slice.
  • Dual TTL ACTIVE_TTL 60s (error) · DONE_TTL 30s (done) hides stale DONE bug; frontend double-filters App.tsx:520 activeOnly running|waiting.

6 — Stack & deployment

Runtime
  • FROM ubuntu:24.04 (Dockerfile:1), node:22, pi 0.84.4 pinned
  • pi-freeflow via pi install → /opt/pi-freeflow + proxy dots clamp 390k
  • Volumes: E:/…:.→/workspace, .pi→/root/.pi, pi-subagents→/tmp/pi-subagents-uid-0
  • Entrypoint trap SIGTERM, tail pi-freeflow.log, heartbeat 300s, optional git-sync/task_watcher
Dashboard
  • Backend Express 4.18 on 3001, server.js:5–676 (reconciler, TTL, dispatch, steer/stop)
  • Frontend React 19 + Vite 8 + Tailwind 4, 1 s poll + SSE /api/fleet/stream
  • CLI dashboard.sh 22 KB — same bus, tput cols, 1 s refresh
  • Workflow coder-tester-loop.js + .pi/prompts/coder-tester-loop.md (3-round cap)

7 — Conventions & reading guide

  • All line refs are file:line as of commit 5d55e68.
  • Normative keywords: must = invariant, should = quality target.
  • Tokens: totalTokens may be number or {total, window, input, output}; reconciler normalizes per server.js:60.
  • State map (canonical): running|pending → running, paused → waiting, complete → done, failed|stopped → error (server.js:96) + stale guard.
  • Host vs container: host E:/projects/pi-harness appears as /workspace inside pi-personal-agent; docs at /workspace/docs served at /docs.
